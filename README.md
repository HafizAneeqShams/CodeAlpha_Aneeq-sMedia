# Aneeq's Media - Social Media Platform

A full-stack social media application built with React, Node.js, Express, and MongoDB. Features include user authentication, posts with images/videos, like/comment system, follow/unfollow, direct messaging, and real-time notifications.

## 🚀 Features

- User Authentication (Register/Login with JWT)
- Profile Management (Bio, Profile Picture)
- Create Posts (Text + Images/Videos)
- Like/Unlike Posts
- Comments with Replies
- Follow/Unfollow Users
- Personalized Feed
- Direct Messaging
- Real-time Notifications
- Responsive UI

## 💻 Tech Stack

**Frontend:** React.js, CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Authentication:** JWT  


## 🛠️ Installation

### Backend

cd backend
npm install
npm run dev


### Frontend

cd frontend
npm install
npm start
